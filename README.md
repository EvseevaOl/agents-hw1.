# Домашнее задание №1
## Создание ИИ-агентов с нуля

**Вариант A — Новичок**

### Цель работы

Сравнить два подхода к разработке мини-трекера учебных задач с использованием ИИ.

**V1 — Direct:** разработка приложения по прямому запросу без предварительной спецификации.

**V2 — Spec:** разработка приложения после создания четырёх документов спецификации в формате OpenSpec (без использования CLI).

### Функциональность

- Добавление и удаление учебных задач.
- Указание времени выполнения в часах.
- Отметка выполненных задач.
- Фильтрация: все, активные, выполненные.
- Расчёт общего количества часов.
- Расчёт прогресса выполнения по часам.
- Проверка корректности вводимых данных.

### Запуск приложения

1. Скачать `tracker-v1.html` или `tracker-v2.html`.
2. Открыть файл в браузере.
3. Проверить функциональность приложения.

Дополнительные библиотеки, сервер и API-ключи не требуются.

### Содержание репозитория

- `tracker-v1.html` — первая реализация.
- `tracker-v2.html` — вторая реализация.
- `proposal.md`, `design.md`, `tasks.md`, `specs/tracker/spec.md` — документы спецификации V2.
- `prompts.txt` — запросы к ИИ и исправления.
- `report.md` — сравнительный отчёт.
- PDF-отчёт со скриншотами проверок.

### Результаты

В первоначальной реализации V1 были обнаружены ошибки в сценариях T1, T3 и T4.

Основная ошибка — неправильный расчёт процента выполнения: приложение показывало 33% вместо 25%, так как учитывало количество задач, а не затраченные часы.

После уточнения требований код V1 был исправлен.

V2 была разработана на основании предварительной спецификации и отработала по исходным требованиям.

Модель: GPT-6.0.

### Вывод

Предварительная спецификация позволяет точнее определить требования к приложению до начала разработки. При использовании прямого запроса может потребоваться дополнительное тестирование и исправление обнаруженных ошибок.
