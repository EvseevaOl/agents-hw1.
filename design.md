# Design — Mini Tracker

## Архитектура

Один автономный файл `tracker-v2.html`: HTML-разметка, CSS-стили и JavaScript встроены внутрь. Без сборки, сервера и внешних пакетов.

## Структура данных

```js
{ id: "unique-id", title: "Чтение", hours: 2, done: true }
```

Стартовые задачи: чтение (2 ч, done), практика (4 ч, active), повторение (2 ч, active).

## Правила

1. `title`: `trim()`, непустая строка.
2. `hours`: непустое числовое значение от 0,5 до 24 включительно, шаг 0,5; пустую строку не превращать в 0.
3. `totalHours = sum(hours)` по всем задачам.
4. `doneHours = sum(hours)` по задачам `done=true`.
5. `progress = totalHours === 0 ? 0 : Math.round(100 * doneHours / totalHours)`.
6. Фильтр меняет только видимый список, не расчёт метрик.
7. После изменения данных обновляются список и итоги.
8. Ошибки показываются возле полей, данные при ошибке сохраняются.

## Пустое состояние

Если задач нет, отображать сообщение о пустом списке, 0 часов и 0%.

## Удобство использования

Подписанные элементы управления; мобильная ширина 390 px без горизонтального скролла. Сохранение в localStorage — необязательное улучшение, при недоступности — работа в памяти и уведомление.
