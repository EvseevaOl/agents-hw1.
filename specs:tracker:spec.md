
# Specification: Учебный трекер

## ADDED Requirements

### Requirement: Отображение задач

Система MUST отображать список задач с названием, оценкой времени в часах и состоянием выполнения.

#### Scenario: Начальное отображение

- **WHEN** пользователь открывает HTML-файл
- **THEN** отображаются три задачи:
  - «Чтение», 2 часа, готово
  - «Практика», 4 часа, активно
  - «Повторение», 2 часа, активно

### Requirement: Добавление задач

Система MUST позволять добавлять новую задачу с названием и оценкой времени в часах.

#### Scenario: Добавление новой задачи

- **WHEN** пользователь вводит название и оценку часов и выполняет добавление
- **THEN** новая задача появляется в списке
- **AND** задача первоначально имеет статус «активно»
- **AND** суммарные часы и процент выполнения пересчитываются

### Requirement: Удаление задач

Система MUST позволять удалять существующие задачи.

#### Scenario: Удаление задачи

- **WHEN** пользователь удаляет задачу
- **THEN** задача исчезает из списка
- **AND** суммарные часы и процент выполнения пересчитываются

### Requirement: Отметка выполнения

Система MUST позволять изменять состояние задачи между «активно» и «готово».

#### Scenario: Завершение задачи

- **WHEN** пользователь отмечает активную задачу как готовую
- **THEN** задача получает статус «готово»
- **AND** процент выполнения обновляется

#### Scenario: Возврат задачи в активные

- **WHEN** пользователь снимает отметку «готово»
- **THEN** задача получает статус «активно»
- **AND** процент выполнения обновляется

### Requirement: Фильтрация задач

Система MUST поддерживать три фильтра: «Все», «Активные», «Готовые».

#### Scenario: Фильтр «Все»

- **WHEN** пользователь выбирает «Все»
- **THEN** отображаются все существующие задачи

#### Scenario: Фильтр «Активные»

- **WHEN** пользователь выбирает «Активные»
- **THEN** отображаются только невыполненные задачи

#### Scenario: Фильтр «Готовые»

- **WHEN** пользователь выбирает «Готовые»
- **THEN** отображаются только выполненные задачи

### Requirement: Суммарные часы

Система MUST отображать сумму оценок времени всех существующих задач.

#### Scenario: Расчёт часов

- **WHEN** список задач содержит оценки 2, 4 и 2 часа
- **THEN** суммарное время составляет 8 часов

#### Scenario: Изменение списка

- **WHEN** пользователь добавляет или удаляет задачу
- **THEN** сумма часов пересчитывается по актуальному списку независимо от выбранного фильтра

### Requirement: Процент выполнения

Система MUST отображать долю выполненных задач от общего количества задач в процентах.

#### Scenario: Начальный процент

- **WHEN** выполнена одна задача из трёх
- **THEN** процент выполнения составляет приблизительно 33,3%

#### Scenario: Все задачи выполнены

- **WHEN** все существующие задачи отмечены как готовые
- **THEN** процент выполнения составляет 100%

#### Scenario: Нет задач

- **WHEN** список задач пуст
- **THEN** суммарные часы равны 0
- **AND** процент выполнения равен 0%

### Requirement: Автономная работа

Система MUST работать как один локальный HTML-файл без внешних ресурсов и установки библиотек.

#### Scenario: Открытие файла

- **WHEN** пользователь открывает HTML-файл в обычном браузере
- **THEN** интерфейс и все предусмотренные функции доступны без внешних зависимостей

### Requirement: Удобный интерфейс

Система MUST предоставлять понятные элементы управления задачами, фильтрами и отображением показателей.

#### Scenario: Использование интерфейса

- **WHEN** пользователь открывает трекер
- **THEN** он видит список задач, элементы управления и сводные показатели
- **AND** может выполнять предусмотренные действия через интерфейс
